# 第一问灵敏度实施契约

本轮依据用户批准的 [Issue #3](https://github.com/Lyxose-Tim/2026CUMCM/issues/3) 和 [Issue #4](https://github.com/Lyxose-Tim/2026CUMCM/issues/4) 执行。基线为 PR #2 的 `0c15e70e89dfc9ce64fc9bd31f135aee20aec0db`；实现分支 `feat/q1-sensitivity` 叠加于该未合并基准。原题、附件、`results/q1/`、`results/result1.xlsx` 和 `figures/q1/` 不覆盖。第二至第四问不在本轮范围。

## 已批准的设计

- 单因素分别扰动 h、hm、D 前因子 ±10%、±20%，共12组及原参数对照。其他参数、初边值和输入数据固定。比例属于人为设定的情景范围，不是参数测量误差分布。
- 每秒21个正式半径上保存温度、干基含水率及体积平均响应；完整内部网格参与推进、包络和余额检查，额外保存最终内部径向场与全部接受步诊断。实验产物独立放在 `results/q1_sensitivity/`。
- 1800 s 主要响应量为中心/表面升温量 ΔT=T−28、中心/表面 C、平均失水量 M=2.55−ΣViCi/ΣVi。M 的单位为 kg水/kg干药材，不是 kg；升温量可与绝对温标转换保持一致，不对摄氏温度作百分比解释。
- 对非零且可解析的基准功能量 Q0，报告中心差分弹性 Sδ=(Q+−Q−)/(2δQ0)，以及 E+=(Q+−Q0)/(δQ0)、E−=(Q0−Q−)/(δQ0)。比较 δ=0.1、0.2 及两侧差异，揭示有限扰动的非线性；不把有限差分称为精确导数。
- 同时报告全时段最大绝对场差、发生位置及1–60 s表面差。对零值/接近零或响应低于数值分辨率者标记不可解释，不加任意 ε。不同物理量分别排序，不相加产生无量纲总分。
- 热湿解耦要求 h 扰动对水分、hm/D 扰动对温度仅有数值级差异；该核验使用实际差值，不裁剪成零。

## 数值门槛和停止条件

生产网格采用已有验证的 N=20480，BDF 设置沿用 `configs/q1.json`。六组 ±20% 极端情景分别比较 N=5120/10240/20480，所有每秒正式节点、早期表面及体积平均均检查；连续两次细化差须下降且落入原空间预算 T≤8e−4 °C、C≤8e−6 kg/kg。实际阶仅为观测，不声称严格误差上界。

这六组在最细网格上另将容差缩小10倍、最大步长减半；再对 hm+20% 和 D前因子−20% 作 Radau 对照，覆盖较强表面传质与较薄早期扩散层。时间差须落入 T≤2e−4 °C、C≤2e−6 kg/kg。±10% 情景位于检查范围内部，但端点复核不构成其误差的数学上界；报告此检查范围，不声称逐参数连续的严格保证。

所有13组生产算例均检查接受步及输出包络、正C、独立表面通量积分余额（≤1e−8，求积差≤1e−10）和早/晚表面残差（≤1%/0.1%）。受影响响应须与复核误差分开报告；很小的中心水分变化不得被全局误差预算掩盖后宣称物理显著。

环境包络推广为初始值和截至当前时刻的环境历史极值。降温时内部温度允许高于瞬时环境温度；增加非单调环境回归验证。水分表面检查必须使用当前参数的 D(C)，避免扰动工况被默认物性误判。

任一门槛失败保留诊断并阻止结果报告和绘图的正式发布。不放宽门槛、不修改物理参数或裁剪接受状态以通过验证。原参数新运行与历史全精度归档对照，旧产物逐文件 SHA256 保护。
