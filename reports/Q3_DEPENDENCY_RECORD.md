# 问题三依赖记录

Q3 复用 Q2 已验证的附录3物性、固定半径空间算子和环境闭合，但从原始初值独立积分。Q2 的 result2 模板只用于输入来源核验，不是 Q3 的数值状态来源；Q3 不读取附件2。

正式配置由 configs/q3.json 指定，唯一正式案例为 N=40960 收紧 BDF。N=5120、10240 和 20480 用于空间、时间与回归对照。

每个 Q3 运行记录保存：

- 题面、附件1、模板及 Q2 归档摘要。
- Python、NumPy、SciPy 与平台版本。
- 数值核心、配置和共享模块的版本化文件摘要。
- 实际积分设置、事件根、诊断及输出文件摘要。

Q3 验证会将 N=20480 同设置结果与 Q2 归档比较，以确认事件驱动器未改变共同物理模型。当前共同时间上的最大差为：温度 4.974e-14 °C，含水率 2.375e-13 kg/kg。

工作簿、图和报告属于交付层，分别由 export_verification.json、figure_manifest.json 和 report_manifest.json 绑定。它们可以在普通 Python 环境及无 Git 源码 ZIP 中核验；code_commit 只说明生成背景，不替代文件级摘要。

历史分支和 PR 状态不属于当前数值依赖。当前复现入口见 Q3_REPRODUCE.md。
