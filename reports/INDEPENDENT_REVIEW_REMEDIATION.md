## R1：跨平台文本证据

- 文本文件按 UTF-8 严格解码，将 CRLF 和单独 CR 统一为 LF，采用 sha256-text-lf-v2。
- NPZ、PDF、XLSX 和原始附件继续采用 sha256-raw-v1。
- 清单中的每个摘要都同时记录 hash_scheme 和 sha256，不再依赖隐式后缀规则。
- 迁移工具只重写证据元数据；迁移前后会核对数值语义，拒绝把数值变化伪装成换行迁移。
- Git 提交读取允许 safe.directory；无 Git 时保留完整源码摘要，存在但不可读时不伪装成 ZIP。

最终验收还会在 LF 干净检出和 git archive 无 Git 解压目录各执行一次 common.portable_audit。

## 物理闭合与论文表达

返修没有凭空加入潜热、相平衡或新参数，而是明确：

1. Ce 是有效边界驱动，不能因同为 kg/kg 就视为与药材干基含水率天然同义。
2. rho(C)cp(C) 是题设有效热容量，rho(C) 不是独立干骨架密度。
3. 热方程不含潜热，不能称为完整焓守恒。
4. Q2/Q3 的 4 h 后环境和 Q4 的输入延拓属于模型情景。
5. 一维径向模型忽略端面，不把端面面积比当作误差界。
6. 当前附件没有内部温湿实测标签，不报告实验准确率。
